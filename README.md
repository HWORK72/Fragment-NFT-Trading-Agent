**Fragment NFT Trading Agent & Quantitative Sniper (C# .NET 8 & Python 3.12)**

This software suite is an automated algorithmic trading system engineered for monitoring the secondary Telegram Gifts and Collectibles marketplace on Fragment, executing quantitative orderbook analysis, detecting undervalued assets, and performing automated on-chain purchases via TON Blockchain smart contracts. The system is built on a highload hybrid architecture combining a compiled quantitative risk engine in C# (.NET 8.0) with an asynchronous network ingestion and cryptographic execution core in Python 3.12. Both engines operate over a shared relational SQLite database and an immediate-flush unified logging pipeline writing to the root logs.txt file.

The C# computational core (FragmentQuant.Engine) handles high-frequency mathematical orderbook processing, computing the 10% Trimmed Mean, median, standard deviation, and market spread depth. The built-in ArbitrageAlphaScorer module evaluates the arbitrage potential of each market segment on a 100-point scale factoring in rarity premiums for dark backdrops (Onyx Black, Obsidian, Pitch Black), while the PortfolioRiskAuditor calculates optimal capital allocation using the mathematical Kelly Criterion and enforces strict portfolio risk boundaries.

The Python network and blockchain core (src/fragment_agent) executes continuous marketplace scraping via an aiohttp connection pool bypassing Cloudflare anti-bot protections, commits market ticks in atomic batches via asynchronous SQLAlchemy 2.0 in 350 milliseconds, synchronizes live wallet balances via HTTPS JSON-RPC TON nodes, and performs offline Ed25519 cryptographic transaction signing for Wallet V4R2 smart contracts.

Preparing the production environment begins with registering a dedicated technical Telegram account and creating a clean non-custodial TON Mainnet wallet in Tonkeeper. Using a personal Telegram profile is not recommended, as purchased collectibles are automatically linked to the connected profile. A working capital deposit of at least 10 to 20 TON is recommended to cover minimum asset prices and blockchain validator gas fees.

To authorize the trading agent to execute purchases on behalf of your account, open fragment.com in a desktop browser, log in via Telegram, and connect your TON wallet. Open Developer Tools (F12), navigate to the Application or Storage tab, select Cookies for fragment.com, and copy the values of stel_token, stel_ssid, stel_ton_token, and stel_dt into the root .env configuration file.

System configuration is managed entirely through the root .env file. Set TON_WALLET_ADDRESS to your public wallet address and TON_WALLET_MNEMONIC to your 24 recovery words enclosed in quotes. Set USE_TESTNET to false for TON Mainnet operation and DRY_RUN to false to enable live on-chain transaction broadcasting. The TARGET_DISCOUNT_PCT parameter defines the required discount below the reference floor price, while MIN_BALANCE_RESERVE_TON enforces a non-spendable gas buffer. Real-time mobile notifications are enabled by configuring TELEGRAM_ALERT_BOT_TOKEN and TELEGRAM_ALERT_CHAT_ID.

To launch the asynchronous scraper and trading supervisor locally, run python main.py. To execute the automated contract and unit test suite, run pytest -v -s test_engine.py. To run the C# quantitative and Kelly risk audit engine, execute dotnet run --project src/FragmentQuant.Engine/FragmentQuant.Engine.csproj. For continuous 24/7 autonomous server operation on Linux Ubuntu, deploy the isolated container via docker compose up -d --build and inspect live telemetry via docker compose logs -f.
