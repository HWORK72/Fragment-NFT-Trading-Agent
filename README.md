Руководство по эксплуатации и запуску торгового комплекса Fragment NFT Trading Agent.

Данный программный комплекс предназначен для автоматизированного мониторинга вторичного рынка подарков Telegram на площадке Fragment, выявления недооцененных лотов и автоматического совершения сделок выкупа через смарт-контракты блокчейна TON. Комплекс включает в себя модуль рыночного парсинга в обход защитных механизмов Cloudflare, статистический анализатор цен с фильтрацией редких визуальных подложек, асинхронную реляционную базу данных SQLite, модуль криптографической подписи транзакций и систему Telegram-уведомлений. Перед запуском комплекса в коммерческую эксплуатацию необходимо выполнить базовую настройку окружения и подключение учетных записей.

Подготовка рабочего пространства начинается с регистрации отдельного технического аккаунта Telegram. В целях безопасности категорически не рекомендуется использовать личный профиль, так как все выкупленные подарки автоматически привязываются к аккаунту и отображаются в профиле. Для торгового робота заводится отдельный номер телефона или eSIM. На этот же номер в официальном приложении Tonkeeper создается чистый некастодиальный кошелек сети TON Mainnet. На созданный кошелек переводится рабочий депозит, при этом минимальная рекомендуемая сумма для комфортной торговли составляет от десяти до двадцати TON с учетом стоимости минимального лота на площадке и комиссий сети.

Для предоставления торговому агенту доступа к совершению покупок от имени вашего аккаунта необходимо извлечь два сессионных параметра с сайта маркетплейса. Откройте браузер на компьютере, перейдите по адресу fragment.com и авторизуйтесь через кнопку подключения Telegram с вашего рабочего номера. После успешного входа нажмите клавишу F12 для вызова панели разработчика, перейдите во вкладку Application или Хранилище, в левом меню выберите раздел Cookies и нажмите на домен fragment.com. В появившейся таблице найдите строки с именами stel_token и stel_ssid, скопируйте их текстовые значения и подготовьте для вставки в конфигурационный файл.

Конфигурация параметров робота осуществляется через системный файл с именем точка env в корневой директории проекта. В строке TON_WALLET_ADDRESS указывается публичный адрес вашего кошелька формата EQ, а в строке TON_WALLET_MNEMONIC в кавычках через пробел записываются все двадцать четыре секретных слова от кошелька. Значения кук вставляются в поля FRAGMENT_COOKIE_STEL_TOKEN и FRAGMENT_COOKIE_STEL_SSID. Параметр USE_TESTNET устанавливается в значение false для работы в боевой сети блокчейна, а параметр DRY_RUN устанавливается в значение false для включения физического списания средств и реального выкупа лотов. Параметр TARGET_DISCOUNT_PCT определяет желаемый процент скидки от минимальной рыночной цены, а MIN_BALANCE_RESERVE_TON задает несгораемый остаток монет для гарантии оплаты газа валидаторов.

Для получения оперативных отчетов о найденных лотах и совершенных сделках на мобильный телефон подключается Telegram-бот. Создайте нового бота через официального BotFather, скопируйте полученный API токен в поле TELEGRAM_ALERT_BOT_TOKEN и обязательно нажмите команду Start в диалоге с созданным ботом. Свой цифровой идентификатор чата можно узнать через бота userinfobot и вставить в строку TELEGRAM_ALERT_CHAT_ID. При обнаружении выгодных предложений бот будет моментально отправлять уведомление с указанием модели подарка, редкости фона, размера дисконта и прямой ссылкой на лот.

Основным и наиболее надежным способом эксплуатации комплекса на удаленном сервере является запуск в изолированном контейнере Docker. На сервере под управлением операционной системы Linux Ubuntu выполните команду установки docker compose up -d --build. Процесс автоматически соберет окружение, подтянет необходимые зависимости, создаст базу данных fragment_market.db и запустит непрерывный мониторинг в фоновом режиме с автоматическим перезапуском при системных сбоях. Просмотр текущих логов и событий в реальном времени осуществляется командой docker compose logs -f.

В случае необходимости локального запуска без использования контейнеров развертывание выполняется через стандартное виртуальное окружение Python версии 3.12. В терминале активируется виртуальная среда, устанавливаются зависимости командой pip install -r requirements.txt и запускается главный файл командой python main.py. Вся история собранных тиков, изменений цен и принятых решений сохраняется в файл базы данных fragment_market.db, который можно в любой момент открыть через любой просмотрщик SQLite для финансового аудита. Для остановки работы комплекса используется стандартная комбинация клавиш Ctrl плюс C, гарантирующая корректное закрытие сетевых сессий без потери данных.
