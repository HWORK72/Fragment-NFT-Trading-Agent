**Руководство по эксплуатации и архитектуре гибридного торгового комплекса Fragment NFT Trading Agent (C# .NET 8 & Python 3.12)**

Данный программный комплекс предназначен для автоматизированного мониторинга вторичного рынка коллекционных подарков Telegram на площадке Fragment, количественного анализа биржевого стакана, выявления недооцененных лотов и автоматического совершения сделок выкупа через смарт-контракты блокчейна TON. Система построена по гибридной высоконагруженной архитектуре, объединяющей компилируемое аналитическое ядро на C# (.NET 8.0) и асинхронный сетевой и криптографический контур на Python 3.12. Оба ядра работают с единой реляционной базой данных SQLite и системой мгновенного логирования в корневой файл logs.txt.

Вычислительное ядро на C# (FragmentQuant.Engine) отвечает за высокочастотную математическую обработку котировок, расчет усеченного среднего (Trimmed Mean), медианы, стандартного отклонения и глубины рыночного спреда. Встроенный скоринговый модуль ArbitrageAlphaScorer оценивает арбитражную привлекательность каждого сегмента по стобалльной шкале с учетом премии за редкие черные фоны (Onyx Black, Obsidian), а модуль PortfolioRiskAuditor рассчитывает оптимальную аллокацию капитала по математическому критерию Келли и контролирует соблюдение лимитов риска.

Сетевой и блокчейн-контур на Python (src/fragment_agent) реализует непрерывный сбор витрин маркетплейса через пул соединений aiohttp в обход защитных механизмов Cloudflare, пакетную запись котировок в базу данных через асинхронную SQLAlchemy 2.0 за триста пятьдесят миллисекунд, синхронизацию живого баланса кошелька через HTTPS JSON-RPC узлы TON и локальную криптографическую подпись транзакций выкупа по стандарту Ed25519 для смарт-контрактов Wallet V4R2.

Подготовка рабочего пространства начинается с регистрации отдельного технического аккаунта Telegram и создания чистого некастодиального кошелька сети TON Mainnet в приложении Tonkeeper. В целях безопасности не рекомендуется использовать личный профиль, так как выкупленные подарки автоматически привязываются к аккаунту. На созданный кошелек переводится рабочий депозит, рекомендуемая сумма для торговли составляет от десяти до двадцати TON с учетом стоимости лотов и сетевых комиссий.

Для предоставления торговому агенту доступа к совершению покупок откройте браузер на компьютере, перейдите на сайт fragment.com, авторизуйтесь через Telegram и подключите ваш TON-кошелек кнопкой Connect TON. Нажмите клавишу F12 для вызова панели разработчика, перейдите во вкладку Application или Хранилище, выберите раздел Cookies для домена fragment.com и скопируйте значения параметров stel_token, stel_ssid, stel_ton_token и stel_dt в конфигурационный файл .env.

Конфигурация параметров робота осуществляется через корневой файл .env. В строке TON_WALLET_ADDRESS указывается адрес кошелька, а в строке TON_WALLET_MNEMONIC в кавычках через пробел записываются двадцать четыре секретных слова. Параметр USE_TESTNET устанавливается в значение false для работы в основной сети блокчейна, а параметр DRY_RUN устанавливается в значение false для включения реального выкупа лотов. Параметр TARGET_DISCOUNT_PCT определяет требуемый процент скидки от рыночного флора, а MIN_BALANCE_RESERVE_TON задает несгораемый остаток монет на оплату газа. Для получения уведомлений в Telegram заполняются поля TELEGRAM_ALERT_BOT_TOKEN и TELEGRAM_ALERT_CHAT_ID.

Для запуска парсера и торгового супервизора используется команда python main.py, для прогона автотестов выполняется команда pytest -v -s test_engine.py, а для запуска аналитического и риск-аудитора на C# используется команда dotnet run --project src/FragmentQuant.Engine/FragmentQuant.Engine.csproj. Для круглосуточной автономной эксплуатации на сервере под управлением Linux предусмотрен запуск через Docker Compose командой docker compose up -d --build с просмотром логов через docker compose logs -f.
